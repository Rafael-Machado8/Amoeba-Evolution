# Dados na versão 0.5.0

O jogo salva progresso, idioma e preferências localmente. Não contém contas, publicidade, compras, analytics ou telemetria próprios. Não envia progresso a servidor.

Exportar cria um JSON. No celular, o jogador escolhe o destino pela folha de compartilhamento do sistema. O serviço escolhido trata essa cópia conforme suas regras. Importar lê somente o arquivo selecionado.

Novo jogo conserva uma cópia de recuperação local. Desinstalar ou limpar dados pode remover o progresso. Backups e diagnósticos do sistema operacional/plataforma dependem das configurações desses serviços.

Não há solicitação de localização, câmera, contatos ou acesso amplo ao armazenamento. O compartilhamento usa um arquivo de cache. O projeto iOS inclui o manifesto de privacidade do acesso a metadados de arquivos internos.

Descrição técnica para o publicador: acrescentar identidade, contato de suporte e hospedagem antes de usar como política pública. Conferir as declarações exigidas pelas lojas na versão efetivamente enviada.
